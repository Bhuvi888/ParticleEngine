## FAQ

**Will it slow down my site?**
No. The demo runs 2,400 particles at 60+ fps on desktop. Rendering is capped
at 2x DPR, the animation pauses under reduced-motion preferences, and the
particle count is configurable.

**Does it work with React / Next.js?**
Yes — there is a dedicated React component with props and a hook for
controlling formations.

**WordPress or plain HTML?**
Yes. The vanilla build is a single ~12 KB script tag; on WordPress it goes in
a child theme or a custom HTML block.

**Can I change the text or colors later?**
Yes. Text is set with one call (`formText("YOUR TEXT")`) and themes are an
object; you get a short customization guide after delivery.

**Will it work on mobile?**
Yes — the canvas sizes itself to its container, rendering is DPR-capped, and
the particle count can be lowered for low-end devices.

**Do I get the source code?**
The integration code is yours on every package. Full repo + build tooling is
available as an extra (or included in Premium — decide before listing).
